## 🧭 What I'm Working On

- 🚗 **Autonomous Racing (FSAC):** perception → localization → planning → control full pipeline integration  
- 🌍 **LiDAR Ground Segmentation:** RANSAC / region-wise modeling, realtime optimization & robustness in cluttered scenes  
- 🧊 **Cone Detection & Clustering:** Euclidean clustering + shape/size validation, false-positive reduction for trackside objects  
- 🧭 **Localization:** EKF fusion + map-based correction (cone map / KD-tree), stable pose in high-speed maneuvers  
- 🧪 **Engineering & Tooling:** ROS (Melodic→Noetic/Jazzy), profiling, parameter management, reproducible experiments with rosbag
