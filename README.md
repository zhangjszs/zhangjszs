## 🚗 Current Focus

### Autonomous Racing

Working on the perception → localization → planning → control pipeline for autonomous racing systems.

Key areas:

* Sensor processing
* Localization
* Path planning
* Vehicle control
* ROS-based system integration
* Real-time debugging & profiling

### 📡 LiDAR Perception

Exploring robust LiDAR processing methods for autonomous racing scenarios.

Current topics:

* Ground segmentation
* RANSAC-based plane fitting
* Region-wise modeling
* Point cloud preprocessing
* Real-time optimization
* Robustness in cluttered environments

### 🟠 Cone Detection & Clustering

Developing point-cloud based cone detection and clustering methods.

Techniques include:

* Euclidean clustering
* Shape & size validation
* Spatial filtering
* False-positive suppression

### 🧭 Localization

Working with sensor fusion and map-based localization.

Current interests:

* EKF
* Cone-map matching
* KD-tree nearest-neighbor search
* Pose estimation
* High-speed localization stability
